# الإدارة المالية

تطبيق عربي محلي لإدارة كاش المحلات، إغلاقات الورديات، الشبكة، المصاريف، إضافة المال ورواتب العمال.

## تشغيل محلي

افتح `index.html` في المتصفح. يحوّل إلى التطبيق الموجود في `11033.html`.

## نشر GitHub Pages

1. أنشئ مستودع GitHub باسم `daftar-ledger` واجعله عامًا.
2. ارفع `index.html` و`11033.html` و`.nojekyll` إلى جذر المستودع.
3. من **Settings → Pages** اختر النشر من الفرع `main` والمجلد `/ (root)`.
4. بعد اكتمال النشر، استخدم الرابط الذي يعرضه GitHub Pages في صفحة الإعدادات.

## الخصوصية والنسخ الاحتياطي

التطبيق لا يرسل بياناته إلى خادم؛ السجلات تبقى في تخزين المتصفح على هذا الجهاز/المتصفح. نشر الموقع يجعل صفحة التطبيق متاحة لمن لديه الرابط، لكنه لا ينقل بيانات المتصفح إلى GitHub. صدّر نسخة احتياطية من داخل التطبيق بانتظام، ولا تضع أي بيانات مالية شخصية داخل ملفات المستودع.
